RIVER TRADING LTD - Images Folder
===================================

Place the following images in this folder:

REQUIRED:
---------
logo-icon.png           → The circular River Trading Ltd logo (the house/RT icon)
                          Save the round logo you shared as this file (PNG preferred).

HERO SLIDER IMAGES:
--------------------
slide-1.jpg             → Slider image 1 (e.g. products display, shop/warehouse photo)
slide-2.jpg             → Slider image 2 (e.g. lubricants, tools in use)
slide-3.jpg             → Slider image 3 (e.g. team, building, or Kigali city)
                          Best size: 1920x1080px (landscape). JPG or PNG both work.

TEAM PHOTOS (About Us page):
------------------------------
These should be professional portrait photos (headshots or half-body).
Best size: 600x700px or similar portrait ratio.

  team-ceo.jpg          → General Manager
  team-sales.jpg        → Sales & Marketing Manager
  team-procurement.jpg  → Procurement Manager
  team-finance.jpg      → Finance Manager
  team-logistics.jpg    → Logistics Manager
  team-cs.jpg           → Customer Service Manager

NOTE: If a photo is missing, a silhouette placeholder will show automatically.
      You can add photos one by one as they become available.

TIPS:
-----
- Logo: PNG with transparent background works best
- Team photos: face should be clearly visible, professional attire preferred
- Slider images: wide/landscape format, avoid text-heavy images
