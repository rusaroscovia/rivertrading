# Electrical product media

For each product, add three JPG photos here using its ID from `js/electrical-products-data.js`:

- `<id>-1.jpg`
- `<id>-2.jpg`
- `<id>-3.jpg`

For example, product ID `1` uses `1-1.jpg`, `1-2.jpg`, and `1-3.jpg`.

Add its muted MP4 background video in `videos/electrical/<id>.mp4`. Videos must be between 5 and 10 seconds long. The video plays silently and loops behind the product name in the details window.
